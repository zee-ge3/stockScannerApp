# Stock Scanner
### Development has been moved private, however you can request access to georgez.xyz by emailing giz@andrew.cmu.edu

## A full-stack application that identifies Volatility Contraction Patterns (VCP) using historical stock data. It scans the NASDAQ for specific technical and fundamental setups and visualizes them for traders.

## Tech Stack

Backend: Python, FastAPI, SQLite, Pandas for data analysis.

Frontend: React, LightweightCharts from TradingView.

Data: Yahoo finance.

## Key Features

Automated screening of every listed NASDAQ ticker.

Customized financial and technical screens.

Visualizes "cup and handle" or VCP patterns.

Backtesting module to verify pattern success rates.
